# Макеты каталога предложений

В каталоге представлены интерфейс для desktop и мобильного экрана, а также состояния загрузки, пустого списка и ошибки API.

- `offers-catalog-desktop.svg` — макет с размером холста 1440 × 1100 px.
- `offers-catalog-mobile.svg` — макет с размером холста 390 × 844 px.

Файлы SVG можно импортировать в Figma как векторные слои. Цвета макета: основной текст `#171A2C`, акцент `#CAFF4A`, фон `#F7F8FC`, поверхности `#FFFFFF`. Подписи типов источника различаются текстом и фоном.
